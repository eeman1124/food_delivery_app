# food_delivery_app
This is a full stack food delivery mobile application that allows users to browse the menu, add items to cart,place orders in real time. The app is built with flutter for a smooth cross-platform experience, powered REST API backend, and uses firebase for authentication an real time data storage.
Features: User Registration and Login (Firebase auth), Browse through the menu, add to cart and place orders, real time order tracking, user profile management, responsive ui for android.
Technologies used are Flutter(dart), Firebase Firestore and auth , REST API, vs code, git.
Setup instructions are flutter sdk installed, node.js installed and a firebase account.
